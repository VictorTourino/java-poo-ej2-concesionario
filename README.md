Concesionario - Java POO Ej2

Gestión básica de un concesionario con clientes, trabajadores y vehículos (coches y motos.

Proyecto de Java orientado a objetos que permite:
  - Registrar clientes, trabajadores, coches y motos.
  - Consultar el vehículo más barato del concesionario.
  - Enviar notificaciones a clientes y trabajadores.
  - Repostar vehículos según su tipo (solo coches).

Se ha puesto en practica la programación orientada a objetos, empleando clases, herencia, interfaces y abstracción.
